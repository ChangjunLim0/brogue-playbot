# Brogue Auto-Player Bot with Gemini AI

[![Code style: black](https://img.shields.io/badge/code%20style-black-000000.svg)](https://github.com/psf/black)
## Project Description

This project is a Python-based bot designed to automate playing the ASCII roguelike game, Brogue(https://github.com/tmewett/BrogueCE). It utilizes Google's Gemini 1.5 Flash AI for both visual screen understanding (VLM) and decision-making (Policy).

This project is developed on Python 3.13
